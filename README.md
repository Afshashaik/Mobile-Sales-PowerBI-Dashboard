# 📱 Mobile Sales Dashboard – Power BI
## 📊 Project Overview

This project presents an interactive Mobile Sales Dashboard
developed using Microsoft Power BI.

The dashboard provides insights into sales performance,
product quantity, transactions, customer ratings, payment
methods, mobile models, cities, and time-based sales trends.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📌 Dashboard Features

### 1. Sales Overview
- Total Sales
- Total Quantity
- Total Transactions
- Average Price
- Sales by City
- Monthly Quantity Trends
- Customer Ratings
- Payment Method Analysis
- Brand Performance
- Mobile Model Performance

### 2. Same Period Analysis
- Total Sales vs Same Period Last Year
- Quarterly comparison
- Monthly comparison
- Year-wise performance

### 3. MTD Analysis
- Month-to-Date sales trends
- Daily sales performance
- Time-based sales analysis

## 📈 Key Insights

- Sales performance varies across different cities and mobile models.
- Customer ratings provide insights into customer satisfaction.
- Payment methods show the distribution of transaction preferences.
- Monthly and quarterly comparisons help identify sales trends.
- MTD analysis provides a detailed view of daily sales performance.

## 🎯 Objective

The objective of this dashboard is to transform mobile
sales data into meaningful business insights through
interactive Power BI visualizations.
